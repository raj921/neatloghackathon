# Parity Medic evidence viewer references

Reviewed October 11, 2026. Links are the reference collection; no remote imagery, fonts or libraries are needed by the viewer.

1. [Design for B2B](https://designforb2b.com): browser review of its curated directory. Separate navigation, a clear task heading and restrained counts; the viewer puts the comparison before supporting evidence.
2. [Minimal Gallery](https://minimal.gallery): sparse editorial hierarchy and generous margins inform the single-column introduction and thin section rules.
3. [FirstRun](https://firstrun.atharvashah.com): reviewed the real entrant's readable Read/Run/Fix/Prove journey. Borrow the clarity of showing a sequence; use our actual measured adapter revisions and a different user job.
4. [Uncut](https://uncut.wtf): reviewed the font categories. Retain the existing project system sans-serif for a portable evidence artifact; use an installed serif for the title as the documented exception below.
5. [Number Flow](https://number-flow.barvian.me): exact values should remain inspectable. Use static tabular numerals; no animated count or React dependency.
6. [tweakcn](https://tweakcn.com): reviewed the theme resource; keep the repository's cream, green and thin-border palette rather than introducing a separate component framework.

[Paper Shaders](https://shaders.paper.design) was also reviewed. A shader would make the text comparison harder to scan, so none is used. DialKit is optional tuning tooling; this view has no animated states to tune.
