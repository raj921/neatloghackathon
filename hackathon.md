# Parity Medic · neatHack

Parity Medic repairs mismatches between a JavaScript adapter and a pinned original implementation, then verifies the revision independently. It addresses silent behavior drift in developer-tool wrappers.

## Known limits

Supported scope is deterministic string interpolation and JSON request preparation against Bruno 4.2.1. The application does not send production HTTP requests. Finite agreement is not universal parity. The backend supports one operator and one process; it requires persistent storage and a running worker. A serverless deployment cannot be described as equivalent without addressing those constraints. Customer demand, proposed pricing and future hosted features are hypotheses.
