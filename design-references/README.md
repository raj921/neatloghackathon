# Recall Relay prototype references

Consulted live October 11, 2026. These links and notes are the reference folder for the throwaway state walkthrough. No external media or libraries are bundled.

1. [Linear](https://linear.app): a readable activity history beside object properties. Use a case history and a compact stock table; avoid dashboard decoration.
2. [GOV.UK Design System](https://design-system.service.gov.uk/): explicit status, clear labels and visible next actions. An unresolved identifier must never appear as a successful clearance.
3. [Minimal Gallery](https://minimal.gallery): restrained hierarchy and whitespace. One large case title, generous outer margins, thin rules.
4. [Search System](https://searchsystem.co): editorial grouping and reference-led navigation. Place the source beside the rule rather than burying it in an activity feed.
5. [Uncut](https://uncut.wtf): consulted for readable typography. Use the platform sans-serif for this portable prototype; no remote font dependency or decorative display face.
6. [Number Flow](https://number-flow.barvian.me): consulted for value changes. Keep numbers static and tabular because this case needs exact, inspectable quantities; no React dependency or count animation.

Additional required resources consulted: [Paper Shaders](https://shaders.paper.design) and [tweakcn](https://tweakcn.com). Neither a shader nor shadcn is needed for a self-contained state demonstration. [DialKit](https://dialkit.dev) could not be retrieved in this environment; no tuning dependency is added. The Design for B2B page also failed to retrieve; the readable references above determine the direction.
